## Кэширование глав вперёд (прослушивание без сети)

Сервис-воркер складывает аудио в хранилище браузера и отдаёт его плееру без сети.

- Настройка «держать N глав вперёд» (0, 1, 2, 3, вся книга) — рядом со скоростью в плеере.
  При старте главы докачивать следующие N в фоне, прослушанные удалять.
- Кнопка «скачать книгу» на странице книги — то же, что «вся книга».

Что учесть:

- Сервис-воркер работает только по HTTPS или на `localhost`. Если библиотека открывается
  по `http://<ip>:3000`, сначала нужен HTTPS (обратный прокси).
- Плеер запрашивает аудио кусками (Range) — воркер должен нарезать их из сохранённого файла.
- Главы по 10–25 МБ, книга около гигабайта. На телефоне браузер может сам очистить хранилище;
  в Safari на iPhone квоты жёстче, а данные сайта без посещений удаляются через неделю.
- Позиция без сети уже копится на устройстве и уходит на сервер при подключении
  (`frontend/src/stores/progressSync.ts`).
